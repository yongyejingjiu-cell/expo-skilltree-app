# Android App Project

このプロジェクトは、Expoを使用したReact Nativeアプリのプロジェクトです。
初心者でも簡単にアプリ開発や動作確認ができるように構成されています。

## 🚀 プロジェクトの概要

これは `android_app` という名前のモバイルアプリプロジェクトです。
JavaScript (React Native) を使って、AndroidやiOSで動くアプリを作ることができます。

## 📋 事前準備 (Prerequisites)

このプロジェクトを実行する前に、以下の準備が必要です。

1. **Node.jsのインストール**: パソコンにNode.jsがインストールされている必要があります。
2. **Expo Goアプリのインストール**: 
   - お使いのスマートフォン（AndroidまたはiPhone）にストアから**Expo Go**アプリをインストールしてください。
   - これを使うと、実機で簡単にアプリの動作を確認できます。

## 🛠️ 使い方 (How to use)

### 1. プロジェクトのセットアップ

まず、アプリを動かすのに必要なツール（ライブラリ）をインストールします。
ターミナル（コマンドプロンプトやPowerShell）を開き、このフォルダの中で以下のコマンドを実行してください。

```bash
npm install
```

### 2. アプリの起動

セットアップが完了したら、以下のコマンドで開発サーバーを立ち上げます。
これがアプリ開発の基本のコマンドです。

```bash
npm start
```

コマンドを実行すると、ターミナルにQRコードが表示されます。

### 3. 実機での確認方法

1. スマートフォンで**Expo Go**アプリを開きます。
2. **Androidの場合**: アプリ内の「Scan QR Code」をタップし、ターミナルに表示されたQRコードを読み取ります。
3. **iPhoneの場合**: 標準のカメラアプリでQRコードを読み取ると、Expo Goで開くことができます。
   - ※同じWi-Fiに接続している必要があります。

しばらく待つと、スマートフォン上で作成したアプリが動きます！

## 💻 よく使うコマンド集

| コマンド | 説明 |
| --- | --- |
| `npm start` | **重要**: 開発サーバーを起動します。QRコードが出ます、 |
| `npm run android` | Androidエミュレータ（PC上の仮想スマホ）または接続されたAndroid端末で起動します。 |
| `npm run ios` | iOSシミュレータ（Macのみ）で起動します。 |
| `npm run web` | Webブラウザでプレビューを確認します。 |

## 💡 初心者向けヒント (Tips)

* **サーバーの停止**: 
  - 実行中のサーバーを止めたいときは、ターミナルをクリックして `Ctrl` キーを押しながら `C` を押します。

* **接続がうまくいかない場合 (Network Error)**: 
  - スマホとPCが同じWi-Fiに繋がっているか確認してください。
  - 公衆Wi-Fiや一部のネットワークでは繋がらないことがあります。その場合は、`--tunnel` オプションを使うとつながりやすくなります。
    ```bash
    npx expo start --tunnel
    ```
    ※ 初回はいくつかインストールの確認が出るかもしれませんが、「y」を押して進めてください。

* **コードの編集**:
  - `App.js` というファイルがアプリのメイン画面です。ここを書き換えて保存すると、スマホの画面もすぐに更新されます（ホットリロード機能）。

楽しんで開発してください！
